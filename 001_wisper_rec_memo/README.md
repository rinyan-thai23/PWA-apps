# 🎙️ Voice Memo Transcriber (001_wisper_rec_memo)

Groq Whisper API（`whisper-large-v3-turbo`）を利用した、超高速・高精度な音声文字起こし＆メモ管理Webアプリ（PWA）。

## ✨ 主な特徴

- **超高速文字起こし**: Groqの高速LPU推論による即時テキスト化（日本語・英語・多言語対応）
- **PWA対応 (Installable)**: iOS Safariの「ホーム画面に追加」、Android Chromeの「アプリをインストール」でネイティブアプリ同様に起動可能
- **音声波形アニメーション**: 録音中の音声をリアルタイムで可視化するモダンUI
- **ローカル管理 & プライバシー保護**: メモデータはすべてブラウザ内に保存。音声データはユーザー指定のGroq APIへ直接送信され、第三者サーバーを経由しません
- **AI要約機能**: 文字起こしメモから重要ポイントを瞬時に箇条書き要約
- **音声・テキストエクスポート**: ワンクリックでのテキストコピー、Web Share APIによる共有、録音音声（WebM/WAV）ダウンロード
