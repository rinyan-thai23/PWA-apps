# 📖 AI Markdown Reader (003_ai_md_viewer)

AI時代のための、長大Markdown専用クライアントサイドWebビューア。  
ChatGPT、Claude、Gemini、DeepSeek等が出力した長文ドキュメントを、**ブラウザにドラッグ＆ドロップするだけで美しく・快適に読める形へ一瞬で変換**します。インストール不要・完全ローカル動作でセキュアに利用可能です。

---

## ✨ 主な特徴と機能

### 1. シンプル操作 & 複数ドキュメント管理
- **どこでもドラッグ＆ドロップ（複数ファイル対応）**: 画面全体またはドロップ枠に複数の `.md` / `.markdown` / `.txt` を一括ドロップ可能
- **ドキュメントタブ切り替え**: 開いたファイルを上部のタブバーで瞬時に行き来（スクロール位置や読破状況もドキュメントごとに自動保持）
- **タブの個別クローズ & 全クリア**: 不要になったタブを「×」で閉じる、または一括全クリア
- **キーボードショートカット対応**: `Alt + ←/→` または `Alt + 1..9` でタブ間を爆速移動
- **クリップボード貼り付け (`Ctrl+V`)**: コピーしたテキストをそのまま新規タブとして即展開
- **ワンクリックサンプル試読**: 2つの異なる設計書サンプル（バックエンド・フロントエンド）が同時展開され、複数タブの快適さを即体験可能

### 2. リッチなMarkdownレンダリング
- **Mermaidダイアグラム**: フローチャートやシーケンス図、ER図をSVGとして自動描画
- **シンタックスハイライト & コードファイル保存**: 各種言語のハイライト、ワンクリックコピーに加え、言語に応じた拡張子（`.py`, `.ts`, `.json`等）で即ファイル保存ダウンロード
- **LaTeX / KaTeX数式**: インライン `$E=mc^2$` およびブロック数式 `$$\dots$$` を美しく組版
- **GitHub風コールアウト**: `[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!IMPORTANT]`, `[!CAUTION]` に対応
- **見出しレベル別カラーリング**: H1〜H6それぞれに直感的な色と装飾を適用
- **テーブル整形 & チェックリスト**: 横スクロール対応の表組みとタスク一覧

### 3. 長文読書に特化したUX & 実務ギミック
- **見出しアコーディオン折りたたみ**: H2/H3セクションをクリックで折りたたみ開閉
- **ドキュメント・メトリクスバー**: 文字数、読了目安時間、見出し数、コードブロック数、図表数をコンパクトに常時表示
- **読了トラッカー & 達成度メーター**: 目次（TOC）に読了進捗バー（%表示）を搭載。読み終えた見出しには自動で「✔」マークが点灯
- **Zen集中読書モード**: ツールバーやサイドバーを非表示にし、文書に没頭（`Esc`で復帰）
- **TL;DR要点ハイライトモード**: 重要コールアウトや太字強調箇所を浮き立たせ、長文から要点を最速抽出
- **ドキュメント内全文検索 (`Ctrl+F`)**: 一致箇所の件数表示と前後のハイライトジャンプ

### 4. オフィス完全対応・静音設計
- **完全静音（サイレント）**: 実務環境やオフィスでも安心して使えるよう音声を一切排除
- **ドロップ演出**: 無音の紙吹雪（Confetti）エフェクト
- **4つの読書テーマ**:
  - 🌌 **サイバーダーク** (デフォルト・未来感のあるネオンアクセント)
  - 🌙 **GitHub Dark** (開発者に親しみやすいコントラスト)
  - 📄 **上質ペーパー** (書籍のように目に優しい白基調)
  - ☕ **カフェセピア** (リラックスして読める暖色系)
- **文字サイズ変更**: `A+` ボタンで4段階のフォントサイズ切り替え
- **印刷 & PDF書き出し最適化**: ナビゲーションを自動非表示にした印刷専用CSSを同梱

### 5. グローバル展開 & SEO・AIエージェント最適化（多言語対応）
- **物理ディレクトリ分割（7言語）**: 各言語に独立したURLパスを割り当て、Google SEOおよびPerplexityやClaude等のAIエージェントによる正確な言語認識・引用を支援
  - 🇯🇵 **日本語 (`ja/`)**
  - 🇺🇸 **English (`en/`)**
  - 🇹🇭 **ไทย (`th/`)**
  - 🇨🇳 **中文 (`zh/`)**
  - 🇪🇸 **Español (`es/`)**
  - 🇩🇪 **Deutsch (`de/`)**
  - 🇫🇷 **Français (`fr/`)**
- **言語選択Hub (`index.html`)**: ルート直下は洗練された言語選択ポータル。ブラウザ言語（`navigator.language`）を自動検知して「おすすめ言語」を強調表示
- **完全なhreflang相互リンク**: 全ページの `<head>` に `rel="alternate" hreflang="..."` を相互配置し、重複コンテンツ判定を防止
- **各言語内クイック言語スイッチャー**: 閲覧画面上部から他言語版へワンタップで遷移可能
- **超軽量・インストール不要**: Service Workerに依存せず、常に最新バージョンがブラウザで爆速動作

## 🚀 起動方法

### ローカルでの起動
本アプリは純粋な静的Webアプリ（SPA）です。

#### 方法1: Python 簡易HTTPサーバー（推奨）
```bash
cd 003_ai_md_viewer
python -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

#### 方法2: `index.html` を直接ブラウザで開く
ブラウザに `index.html` をドラッグ＆ドロップまたはダブルクリックするだけでそのまま動作します。

## 🔒 プライバシー & セキュリティ
- 読み込んだドキュメントやクリップボードの内容は、**すべてブラウザのメモリ上でのみ処理**されます。外部サーバーへの送信は一切行われません。
