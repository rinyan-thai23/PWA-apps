# 🌿 AI Token Squeezer (01_ai_token_squeezer)

AIコンテキスト脱脂・トークン軽量化ツール。  
ChatGPT、Claude、Gemini、Cursor等に長大なテキスト、プロンプト、ソースコード、JSONを渡す前に、**意味を損なわずに無駄な空白・コメント・不要な空行を削除し、最大30〜50%のトークンを削減**する完全クライアントサイドWebツール。

## ✨ 主な機能

- **リアルタイムトークン見積もり**: 入力と脱脂後の推定トークン数をリアルタイム比較
- **削減率プログレスメーター**: 「🎉 48% 削減 (1,850 tokens saved)」をビジュアル表示
- **選べる脱脂ルール**:
  - 重複空白・空行の圧縮（Collapse excessive spaces & lines）
  - 行頭・行末の不要トリム（Trim line whitespace）
  - ソースコード等のコメント削除（`//`, `/* */`, `#`, `<!-- -->`）
  - JSONの最小化（Minify JSON）
- **ワンクリック操作**: クリップボード貼り付け、ワンクリック結果コピー、ファイルD&D対応
- **完全プライベート**: 100%ブラウザ内メモリ処理。外部サーバーへデータを一切送信しないため、機密コードや社外秘文書でも安心して利用可能
- **PWA非該当（純粋なWebユーティリティ）**: インストール不要、ブックマーク感覚で即座に動作
