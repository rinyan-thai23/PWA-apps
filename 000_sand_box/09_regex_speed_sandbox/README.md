# Regex Speed Sandbox (即席正規表現チェッカー＆キャプチャグループ抽出機)

## 概要
正規表現（Regular Expression）の動作検証、マッチ箇所のリアルタイム色分けハイライト、およびキャプチャグループ（Group 1, Group 2...）のテーブル一覧抽出とJSON/CSVエクスポートを1ミリ秒で即座に行う高速Webユーティリティです。

100%クライアントサイド（ブラウザ内完結）で動作するため、外部サービスに機密ログや個人情報を送信する情報漏洩リスクが一切ありません。

画面上部には実務で頻出する「メール抽出」「URL抽出」「ログ抽出」「HTTPステータス」「IPアドレス」などのプリセットボタンが並び、どんな正規表現をどのようなテキストに対して適用すればよいかが一目で直感的にわかる設計となっています。

- **PWA区分**: PWA非該当（Web Utility）
- **プライバシー**: 100% クライアントサイド処理（完全静音・サーバー通信ゼロ）
- **サンプルデータ**: `sample.txt` (HTTPアクセスログ・APIレスポンスの実務ログサンプル)

## 主な機能
1. **リアルタイム・マッチハイライト**:
   - パターンやテキストの入力と同時に、マッチした箇所を色分け（パープル背景）で即時表示
2. **正規表現フラグのGUIトグル**:
   - `g` (全件マッチ)、`i` (大文字小文字無視)、`m` (複数行モード)、`s` (ドット改行許可) の個別トグル
3. **キャプチャグループのテーブル抽出**:
   - `( ... )` でグループ化した各要素を「Full Match」「Group 1」「Group 2」と表形式で整理して一覧表示
4. **構造化データエクスポート**:
   - 抽出結果をワンクリックでJSONオブジェクト配列、改行区切りリストとしてコピー可能
5. **構文エラーの即時検知**:
   - 閉じ括弧漏れや無効な量指定子などのRegExpSyntaxErrorを検知し、インラインエラーバナーで原因を通知
6. **一目でわかるクイック実用プリセット**:
   - メール、URL、ログレベル、ステータスコード、IPアドレス抽出のプリセットボタンを搭載
7. **外部サンプルの自動非同期読み込み**:
   - 開いた瞬間に `sample.txt` を読み込み、すぐにマッチング効果を体感可能
