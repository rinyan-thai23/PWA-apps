# Cron Human Translator (Cron式 人間語翻訳＆次回発火予測)

## 概要
暗号のように難解なCron式（例: `*/15 0-6 * * 1-5`, `0 9 * * 1-5`, `0 0 1,15 * *` など）を、誰でも一目でわかる自然な人間語（日本語・英語）に瞬時に翻訳し、次回以降の実行スケジュール（直近5回分のJST/UTC日時および相対残り時間）をリアルタイムに予測・表示するWebユーティリティです。

画面上部には実務でよく使われる典型的なCron式のクイックサンプルチップが並び、どんなデータを入力すればよいかが一目で直感的にわかる設計となっています。

- **PWA区分**: PWA非該当（Web Utility）
- **プライバシー**: 100% クライアントサイド処理（完全静音・サーバー通信ゼロ）
- **サンプルデータ**: `sample.txt` (実務で多用されるCron式と解説データ)

## 主な機能
1. **自然言語（人間語）リアルタイム翻訳**:
   - 標準5フィールド（分・時・日・月・曜日）を即座に解析し、「平日(月〜金)の 0時〜6時台の間、15分ごとに実行」などの分かりやすい文章へ翻訳
2. **次回以降の発火スケジュール予測 (直近5回分)**:
   - 現在時刻を基準に、次にいつ実行されるかをシミュレーション計算
   - ローカル日時（JST）と国際標準時（UTC）を併記、さらに「○分後」「○時間後」の相対時間カウントを表示
3. **フィールド別分解インジケーター**:
   - 入力された各フィールド（分・時・日・月・曜日）を個別にカード表示
4. **一目でわかるクイック入力プリセット**:
   - 「平日毎朝9:00」「15分おき」「月2回締め処理」「常時5分おき」「日曜深夜メンテナンス」などのボタンをクリックするだけで即時反映
5. **外部サンプルの自動非同期読み込み**:
   - 開いた瞬間に `sample.txt` を読み込み、すぐに翻訳と発火予測を体感可能
