# Secret Leak Blocker (機密データ・マスク消去機)

## 概要
サーバーログや設定ファイル（`.env`）、エラースタックトレース、シェル実行履歴などをChatGPTなどのAIチャットやGitHub Issues、サポートチケットに貼り付ける際、誤ってAPIキー、アクセストークン、プライベートIP、メールアドレス、秘密鍵、クレジットカード情報が混入・漏洩する事故を防止するためのWebユーティリティです。

100%ローカルブラウザ上で動作し、既知の機密パターンを正規表現・ヒューリスティクスで一括検知し、安全にマスキングされたテキストへ即座に変換・コピーできます。

- **PWA区分**: PWA非該当（Web Utility）
- **プライバシー**: 100% クライアントサイド処理（完全静音・サーバー通信ゼロ）
- **サンプルデータ**: `sample.log` (実用的なサーバー初期化ログ＆各種機密を含むテストログファイル)

## 主な機能
1. **多重パターンによる機密検知**:
   - **APIキー・トークン**: OpenAI (`sk-...`), AWS Access Key (`AKIA...`), AWS Secret, GitHub Token (`ghp_...`), Stripe Secret (`sk_live_...`), Slack Bot Token (`xoxb-...`), データベースパスワードURL
   - **秘密鍵**: RSA / SSH Private Key ブロック (`BEGIN PRIVATE KEY` ...)
   - **認証トークン**: JWT (`eyJ...`)
   - **IPアドレス**: IPv4、IPv6
   - **メールアドレス**: RFC準拠のメールアドレス
   - **クレジットカード番号**: 16桁カード番号
   - **電話番号**: 国際電話番号 / ハイフン区切り電話番号
2. **選べる3つのマスキング方式**:
   - **マスク保護**: 前後数文字を残して安全に伏字化 (`sk-proj-****...****`, `u****r@example.com`)
   - **タグ置換**: 意味がわかるプレースホルダー化 (`[REDACTED_API_KEY]`, `[REDACTED_EMAIL]`)
   - **シンプル削除**: 一律 `[REDACTED]` 化
3. **検知統計・カテゴリ別件数表示**:
   - 「18件の機密を検知＆マスク」など、検知された内訳をバッジ表示
4. **ワンクリックコピー＆ファイル保存**:
   - サニタイズ済みテキストをクリップボードコピー、または `.txt` としてダウンロード
5. **外部サンプルの自動非同期読み込み**:
   - 開いた瞬間に `sample.log` を読み込み、即座にマスキング効果を体感可能
