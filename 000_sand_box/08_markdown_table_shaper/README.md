# Markdown Table Shaper (超速マークダウン表整形＆スプレッドシート相互変換)

## 概要
手書きやコピペで列幅がガタガタになってしまったMarkdownの表（Table）の余白パディングを自動計算し、パイプ `|` の位置が綺麗に揃った美しいMarkdown表に整形するWebユーティリティです。

さらに、ExcelやGoogleスプレッドシートからコピーしたTSV（タブ区切りテキスト）やCSVを貼り付けるだけで、即座にGitHub対応のMarkdown表へ自動変換。HTML `<table>` プレビュー、CSV、TSV、JSONオブジェクト配列への相互変換・エクスポートにも対応しています。

- **PWA区分**: PWA非該当（Web Utility）
- **プライバシー**: 100% クライアントサイド処理（完全静音・サーバー通信ゼロ）
- **サンプルデータ**: `sample.md` (クラウドサーバー仕様比較の実務テーブルデータ)

## 主な機能
1. **余白パディングの自動整形**:
   - 各列の最大文字幅（全角文字・日本語幅も考慮）を自動算出し、縦ラインが美しく揃ったMarkdown表を出力
2. **スプレッドシート（TSV）/ CSV からの即時変換**:
   - 表計算ソフトからセル範囲をコピーして貼り付けるだけでMarkdown表に自動変換
3. **整列（アライメント）の一括指定**:
   - 左揃え (`:---`)、中央揃え (`:---:`)、右揃え (`---:`) をワンクリック切り替え
4. **多彩な出力形式**:
   - 整形Markdown、HTMLテーブルリアルタイムプレビュー、CSV、TSV、JSON
5. **一目でわかるクイック入力プリセット**:
   - 「ガタガタMarkdown表」「スプレッドシート(TSV)」「カンマ区切り(CSV)」のサンプルボタンを配置し、入力形式を直感的に理解可能
6. **外部サンプルの自動非同期読み込み**:
   - 開いた瞬間に `sample.md` をロードし、すぐに整形効果を体感可能
