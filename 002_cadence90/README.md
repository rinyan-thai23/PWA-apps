# 002: ケイデンス90タイマー（spn90.com）

自転車・ロードバイクのペダリングケイデンス（RPM）を「耳で覚える」ためのリズムガイド＆室内インターバルトレーニングPWA（Progressive Web App）です。

---

## 📱 特徴・機能

- **PWA対応（完全オフライン動作）**:
  - ホーム画面への追加（インストール）に対応
  - Service Workerによるオフラインキャッシュ（電波の届かない山道や屋外でも安心）
  - 走行中の画面自動スリープ防止（Screen Wake Lock API連携）
- **車道モード（実走用）**:
  - 指定ケイデンス（40〜140 RPM）に合わせたリアルタイムビート音
  - ペダルを踏むたび（1回転に2回）または1回転に1回の切り替え
  - 視認性の高いクランク回転アニメーション
- **室内トレーニングモード**:
  - A/Bパターンのインターバルタイマー（設定時間・ケイデンスの自動切り替え）
  - カスタムプログラム作成・ローカル保存
  - 音声読み上げ＆切り替え3秒前カウントダウン
  - フロント（アウター/インナー）× リア（スプロケット段数）ギア比・タイヤ周長シミュレータ（推定時速 km/h 表示）
  - 日次回転数・走行距離ログ
- **多彩な音色**:
  - スタンダード、木魚、クリック、曜日替わりなど
