# 002: ケイデンス90タイマー（spn90.com）

自転車・ロードバイクのペダリングケイデンス（RPM）を「耳で覚える」ためのリズムガイド＆室内インターバルトレーニングPWA（Progressive Web App）です。

---

## 📱 特徴・機能

- **PWA対応（完全オフライン動作）**:
  - ホーム画面への追加（インストール）に対応
  - Service Workerによるオフラインキャッシュ（電波の届かない山道や屋外でも安心）
  - 走行中の画面自動スリープ防止（Screen Wake Lock API連携）
  - **ロック画面リモコン（MediaSession API）**: スマホをロックした状態やイヤホンの操作ボタンから「前へ（-5 RPM）」「次へ（+5 RPM）」「再生/一時停止」のリモート操作が可能。現在の回転数もロック画面上にリアルタイム表示。
- **車道モード（実走用）**:
  - 指定ケイデンス（40〜140 RPM）に合わせたリアルタイムビート音
  - ペダルを踏むたび（1回転に2回）または1回転に1回の切り替え
  - 視認性の高いクランク回転アニメーション
- **室内トレーニングモード**:
  - **大画面HUDモード（全画面計器ビュー）**: モニターやタブレットでの横画面トレーニングに最適化された専用ダッシュボード。巨大カウントダウン、次予告バナー、巨大ケイデンス＆速度計をワンタップ（またはFキー）で展開。
  - **ゾーンカラー演出**: ケイデンス域に応じた4色のリアルタイムネオングロー（〜75: 青/ウォームアップ、76〜95: 緑/巡航、96〜110: 黄/高回転、111〜: 赤/スプリント）。
  - **リアルな歯数表記（50T / 34T）**: フロントギアもリアスプロケットと同様に実際の歯数で表示・変速。コンパクト・ノーマルや任意入力に対応。
  - A/Bパターンのインターバルタイマー（設定時間・ケイデンスの自動切り替え）
  - カスタムプログラム作成・ローカル保存
  - 音声読み上げ＆切り替え3秒前カウントダウン
  - フロント×リアギア比・タイヤ周長シミュレータ（推定時速 km/h 表示）
  - キーボード操作対応（Space: 開始/停止、←/→: ±5 RPM、↑/↓: 変速、F: 全画面HUD）
  - 日次回転数・走行距離ログ
- **多彩な音色**:
  - スタンダード、木魚、クリック、曜日替わりなど
